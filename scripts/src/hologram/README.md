# 홀로그램 4면 변환기

영상 하나를 받아 페퍼스 고스트 피라미드(투명 사각뿔)에 올려 볼 수 있는 4면 정사각형 영상(MP4)으로 바꿉니다. 같은 영상을 위·아래·왼쪽·오른쪽 네 곳에 90°씩 돌려 배치하고, 가운데는 비워 둡니다.

```
        ┌───────────────┐
        │╲     위      ╱│
        │  ╲         ╱  │
        │왼 │ 가운데 │ 오│
        │  ╱  (빈칸) ╲  │
        │╱    아래     ╲│
        └───────────────┘
```

## 준비물

- ffmpeg (PATH에 있어야 합니다)
- Node.js와 pnpm (`pnpm install` 한 번)

## 사용법

```bash
pnpm --filter @workspace/scripts run hologram -- 입력.mp4
# → 입력-hologram.mp4 (1080x1080)

pnpm --filter @workspace/scripts run hologram -- 입력.mp4 -o 출력.mp4 --size 1440 --gap 360
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o, --output` | `<입력>-hologram.mp4` | 출력 경로 |
| `-s, --size` | 1080 | 출력 정사각형 한 변(px, 짝수) |
| `-g, --gap` | size의 1/4 | 가운데 빈 정사각형 한 변(px). 피라미드 아래쪽 작은 구멍 크기에 맞춥니다 |
| `--scale` | 1 | 패널 안에서 영상이 차지하는 비율(0~1) |
| `--heads` | `outward` | `outward`: 영상 위쪽(머리)이 화면 가장자리를 향함. 폰·태블릿을 바닥에 두고 피라미드를 뒤집어(좁은 쪽이 아래로) 올리는 일반적인 방식입니다. `inward`: 머리가 가운데를 향함 |
| `--no-flip` | 보정 켜짐 | 거울 반사 보정을 끕니다. 기본값은 반사로 좌우가 뒤집히는 것을 미리 되돌려서 글자가 똑바로 보이게 합니다 |
| `--no-mask` | 마스크 켜짐 | 대각선 마스크를 끕니다. 기본값은 각 패널을 자기 삼각형 영역으로 잘라 이웃 패널과 겹치지 않게 합니다 |
| `--key` | 없음 | 이 배경색을 검은색으로 바꿉니다(예: `green`, `0x00FF00`) |
| `--key-similarity` | 0.15 | `--key` 색과 얼마나 비슷한 색까지 지울지(0.01~1) |
| `--fps` | 30 | 출력 프레임레이트 |
| `--crf` | 18 | x264 화질(낮을수록 고화질) |
| `-t, --duration` | 전체 | 앞부분 N초만 변환(테스트용) |
| `--no-audio` | 오디오 유지 | 오디오를 뺍니다 |
| `--print-filter` | | ffmpeg 필터 그래프만 출력합니다 |

## 좋은 결과를 위한 팁

- **배경은 검은색이어야 합니다.** 피라미드에서는 검은색이 투명하게 보이고 밝은 부분만 떠 보입니다. 처음부터 검은 배경으로 만든 영상이 가장 좋습니다.
- `--key`는 그린스크린처럼 피사체와 확실히 다른 단색 배경에만 쓰세요. 분홍 배경처럼 피부색과 가까운 색을 지우면 얼굴까지 지워집니다.
- 피라미드 아래쪽 구멍 크기에 맞춰 `--gap`을 조절하세요. 예를 들어 화면 한 변이 15cm인데 구멍이 1cm라면 1080 × 1/15 ≈ 72px입니다.
- 화면 밝기를 최대로 하고 주변을 어둡게 하면 훨씬 잘 보입니다.

## 동작 방식

1. 입력을 패널 크기의 정사각형 박스에 비율을 유지해 맞춥니다(남는 곳은 검은색).
2. 아래 패널 방향으로 돌리고(`--heads`), 거울 보정이 켜져 있으면 좌우를 한 번 더 뒤집습니다.
3. 아래 삼각형 마스크를 곱한 뒤, 캔버스를 180°·90°·-90° 돌려 나머지 세 패널을 만들고 합칩니다.

코드는 `layout.ts`(필터 그래프 생성)와 `cli.ts`(옵션 처리·ffmpeg 실행)로 나뉩니다.
