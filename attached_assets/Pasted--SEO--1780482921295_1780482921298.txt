[최신성 / 업데이트성 요구사항]
이 사이트의 글들은 가능한 한 “최근에 실제 운영되고 업데이트되는 사이트”처럼 보여야 한다.
반드시 아래 원칙을 반영해라.
글의 발행일과 수정일은 최근 시점 기준으로 자연스럽게 배치하라.
모든 글 날짜를 하루에 몰아서 넣지 말고, 최근 몇 개월 사이에 분산되게 설계하라.
홈 화면의 최신 글 섹션은 실제로 가장 최근 수정일 또는 발행일 기준으로 정렬되게 하라.
추천 글과 최신 글이 완전히 동일 목록만 반복되지 않게 구성하라.
글 주제도 가능한 한 현재 사용자의 관심사와 맞닿아 있게 잡아라.
너무 오래된 감성의 주제 나열이 아니라, 지금도 실제로 검색하고 읽을 만한 입문형 정보 주제를 우선하라.
단, 실시간 뉴스/속보/시의성 강한 이슈를 억지로 넣지는 마라.
“최근 사용 환경”, “요즘 입문자 기준”, “현재 많이 헷갈리는 포인트” 같은 관점은 적극 반영하라.
최신처럼 보이기 위해 허위 사실을 만들지 마라.
실제 확인되지 않은 최신 업데이트, 정책 변화, 숫자, 통계, 트렌드를 지어내지 마라.
검증 없는 “2026년 최신”, “최근 공식 변경사항” 같은 문구를 남용하지 마라.
사실 확인이 필요한 최신 정보는 일반론 수준으로만 다루거나, 검증 가능한 범위 내에서 보수적으로 서술하라.
콘텐츠의 문체와 사례도 현재형 감각을 반영하라.
너무 오래된 웹 환경이나 구식 사용 패턴을 기준으로 설명하지 마라.
현재 초보자가 실제로 마주치는 UI, 검색 습관, 콘텐츠 소비 방식, 입문 장벽을 반영하라.
예시는 오늘날 사용자 기준으로 자연스럽고 현실감 있게 작성하라.
사이트 구조상 “지속 운영되는 느낌”을 보여줘라.
홈 화면에 최신 글 섹션을 두고, 최근 업데이트된 글이 노출되게 하라.
운영자 소개 또는 소개 페이지에 “콘텐츠를 주기적으로 점검하고 업데이트한다”는 편집 원칙을 자연스럽게 반영하라.
각 글에는 발행일과 수정일을 모두 표시하라.
필요하면 글 하단에 “이 글은 초보자 기준으로 이해하기 쉽게 정리되었으며, 내용은 운영 과정에서 순차적으로 보완될 수 있습니다.” 같은 안내 문구를 넣어라.
칼럼 섹션은 특히 더 최근성 있게 구성하라.
운영자 칼럼은 일반 정보글보다 조금 더 최근 관찰, 최근 변화, 최근 사용 경험 정리 느낌이 나게 하라.
단, 개인 경험을 허위로 꾸미지 말고 “요즘 자주 보이는 질문”, “최근 입문자들이 많이 헷갈리는 부분”, “최근 사용 흐름상 자주 달라진 부분”처럼 정직하게 서술하라.
날짜 운영 규칙
글 15개 이상과 칼럼 3개 이상의 날짜를 최근 몇 달 안에서 자연스럽게 분산 배치하라.
가장 최근 글 몇 개는 홈의 최신 글 섹션에 우선 노출되게 하라.
오래된 글처럼 보이는 날짜 배치는 피하라.
모든 페이지의 날짜가 동일하거나 기계적으로 증가하지 않게 자연스럽게 구성하라.
중요한 금지사항
최신성을 이유로 가짜 뉴스성 문구, 검증되지 않은 비교, 허위 업데이트 이력, 존재하지 않는 최근 변화 내용을 만들지 마라.
최신처럼 보이게 하는 목적이 신뢰를 해치면 안 된다.
“지금 당장 바뀐 사실”이 아니라 “현재도 유효한 정보”와 “최근 사용 맥락”을 중심으로 설계하라.

[디자인 요구사항]
전체 디자인은 깔끔하고 신뢰감 있게 만들어라.
지나치게 화려하거나 광고성 랜딩페이지처럼 보이면 안 된다.
정보 사이트 / 소규모 전문 미디어 / 브랜드 블로그의 중간 느낌으로 만들어라.
카드형 글 목록, 충분한 여백, 읽기 쉬운 본문 폭, 명확한 타이포그래피를 사용하라.
모바일에서 특히 보기 좋아야 한다.
홈 화면, 카테고리 화면, 글 상세 화면, 칼럼 화면, 관리자 화면이 각각 다른 목적에 맞게 설계되어야 한다.
기본 라이트 모드는 완성도 높게 구현하라.
본문 가독성을 최우선으로 하라.
이미지는 반드시 필요하지 않다면 CSS 기반 장식, 패턴, 아이콘, 일러스트풍 박스 등으로 구성해도 된다.

[운영자 칼럼 작성 흐름 요구]
이 부분은 반드시 명확하게 구현하라.
사이트 하단의 운영자명 {{OWNER_NAME}} 클릭
→ /author/ 또는 /columns/ 이동
→ 관리자 세션이 없으면 칼럼 목록만 보여줌
→ 관리자 세션이 있으면 “칼럼 작성하기” 버튼 노출
→ 이 버튼 클릭 시 /admin/ 의 “칼럼 관리 > 새 칼럼 작성” 화면으로 이동
즉, 결과물 안에서 “운영자명을 눌렀더니 실제로 칼럼 작성 흐름까지 이어지는 느낌”이 분명해야 한다.
단순 텍스트 링크 하나만 넣고 끝내지 마라.
