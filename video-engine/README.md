# 무대형 모션 영상 엔진 (p5.js)

대본 JSON 하나를 넣으면 "종이 질감 무대 + 퍼펫 마스코트 + 카드형 인포그래픽" 스타일의 설명 영상을 재생하고 WebM으로 녹화하는 p5.js 엔진입니다. 주제가 바뀌어도 내러티브 구조, 편집 리듬, 전환, 효과음, 타이포가 같은 규칙으로 나오도록 만들었습니다.

참고한 영상은 Ai-Con Lab의 「120시간동안 오퍼스 5.5로 모션그래픽을 테스트해봤다」(youtu.be/J4PbF8_u6pY)입니다. 이 엔진은 그 영상의 **형식**(장면 구성 순서, 무대·커튼 모티프, 카드·이젤·빨랫줄 같은 그래픽 어휘, 효과음 종류, 자막 스타일)을 분석해 다시 구현한 것입니다. 원본의 대본·캐릭터·음악·영상 프레임은 복사하지 않았고, 마스코트(디노), BGM, 효과음은 모두 코드로 새로 만들었습니다.

## 실행

```bash
cd video-engine
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 바로 열어도 동작합니다. 인터넷 연결이 있어야 p5.js(cdnjs)와 폰트(Google Fonts: Jua, Gowun Dodum)를 불러옵니다.

| 조작 | 동작 |
|---|---|
| 스페이스 / ▶ 재생 | 재생·일시정지 (←/→ 2초 이동) |
| ● WebM 녹화 | 처음부터 끝까지 실시간 재생하며 화면+효과음+BGM을 WebM으로 저장 |
| ▦ 컨택트시트 | 영상 전체를 24장으로 뽑아 한 장 PNG로 저장 (눈 검수용) |
| 대본 JSON 불러오기 | 또는 JSON 파일을 화면에 끌어다 놓기 |
| TTS 미리듣기 | 브라우저 음성으로 say를 읽어 줌 (녹화에는 포함 안 됨) |

## 내 주제로 만들기

1. `PROMPT.md`의 프롬프트에 주제나 원고를 넣어 Claude에게 대본 JSON을 받습니다.
2. 받은 JSON을 화면에 끌어다 놓고 재생해 봅니다.
3. 내레이션 녹음이 있으면 `meta.voice`에 오디오 파일 경로를 넣고, 각 장면 `dur`을 녹음 타이밍에 맞춥니다. 그러면 녹화 파일에 목소리까지 함께 들어갑니다.
4. 컨택트시트로 전체를 훑고, 마음에 들면 WebM 녹화.

`examples/all-scene-types.json`은 모든 장면 타입을 한 번씩 쓴 견본이고, `script.js`는 기본으로 뜨는 데모(「일주일에 책 한 권」)입니다. 데모 속 숫자는 연출 예시용 가정값입니다.

## 구조

```
video-engine/
├─ index.html          UI · 재생 컨트롤
├─ script.js           데모 대본 (window.SCRIPT_DATA)
├─ PROMPT.md           주제 → 대본 JSON 변환 프롬프트
├─ examples/           JSON 견본
└─ src/
   ├─ lib.js           상수 · 이징 · 카드/텍스트 헬퍼
   ├─ tones.js         톤 카드 (stage / dark / minimal 색·폰트)
   ├─ graphics.js      무대 · 커튼 · 아이콘 26종 · 미니 화면
   ├─ mascot.js        오리지널 마스코트 "디노" (표정 7종, 걷기)
   ├─ scenes.js        장면 타입 14종 (그림 + 효과음 큐)
   ├─ audio.js         Web Audio 효과음 16종 + 어쿠스틱 BGM 합성
   └─ engine.js        타임라인 · 전환 · 자막 · 녹화 · 컨택트시트
```

## 스타일 규칙 (분석 결과를 코드로 옮긴 것)

화면 구성은 크림·올리브·보라 계열 벽 + 나무 바닥 + 양옆 붉은 커튼과 금색 장식이 기본이고, 정보는 항상 두꺼운 외곽선의 크림색 종이 카드(#FFF9E6) 위에 올립니다. 자막은 하단 중앙에 둥근 굵은 고딕(Jua), 흰 글자에 진한 외곽선을 두르고 `*강조*` 단어만 노랗게 표시합니다.

편집은 장면당 3~8초 리듬으로, 요소는 탄성 있게 튀어나오고(easeOutBack) 걸리고(빨랫줄 흔들림) 찍히는(도장) 동작을 씁니다. 장면 사이 기본 전환은 `flow`로, 마스코트가 다음 위치로 걸어가는 동안 벽색이 바뀌고 내용이 옆으로 흘러 들어와 "막이 내려가지 않는 연극"처럼 이어집니다. 첫 장면은 커튼이 열리고, 분위기를 끊어야 하는 장면(함정 비교)과 마지막은 커튼이 닫힙니다.

효과음은 등장마다 팝, 타이핑에 틱, 집게에 스냅, 정답에 딩, 오답에 버즈, 전환에 휘익·커튼 소리를 넣고, 바닥에 92BPM 어쿠스틱 기타 스트럼 루프를 낮게 깝니다. 등장 시각을 그림과 소리가 같은 함수(`revealTimes`)로 계산하기 때문에 화면과 소리가 어긋나지 않습니다.

## 확장

새 장면 타입은 `scenes.js`에 `SCENES.이름 = { mascot, draw(s, t, d), cues(s, d) }`를 추가하면 됩니다. 새 톤은 `tones.js`의 `TONES`에 색 묶음을 더하고 `meta.tone`으로 고릅니다.
