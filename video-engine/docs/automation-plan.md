# 톤 카드 영상 자동화 사이트 기획서

## 1. 목표

주제 한 줄(또는 추천 주제 하나)만 고르면 **대본 → 내 목소리 내레이션 → 모션그래픽 영상 → 검수 → 업로드 대기**까지 사람 손을 최소로 거쳐 나오게 한다. 품질이 매번 흔들리지 않도록 "멋있게 만들어 줘" 대신 **톤 카드(규칙 11개 + 목표 숫자)** 를 넘기고, 결과물은 **만든 AI가 아니라 측정 코드가** 채점한다. 검수에서 나온 실수는 **실수 노트**에 규칙으로 쌓여 다음 영상의 품질이 된다.

## 2. 지금 만들어진 것 (1단계: 로컬 스튜디오)

| 단계 | 화면 | 하는 일 | 사용 기술 |
|---|---|---|---|
| ① 톤 고르기 | 톤 카드 11장 | 주인공·바탕·색·글꼴·자막·움직임·전환·카메라·효과음·음악·금지 + 목표 숫자(장면 길이·밝기·움직임) | `src/tones.js` |
| ② 주제·대본 | 주제 입력, 톤별 추천 주제, AI 주제 추천, 길이(쇼츠·표준·롱폼), 참고 자료 | 톤 카드 + 구조 + 실수 노트로 프롬프트를 만들어 Claude가 장면 JSON을 씀 | Claude API (`claude-opus-5-5`) |
| ③ 목소리 | Cartesia 목소리 ID | 장면마다 내 클론 목소리로 내레이션 생성, 단어별 시간표로 자막·장면 길이 자동 맞춤 | Cartesia `/tts/sse` (`add_timestamps`) |
| ④ 미리보기 | p5.js 캔버스 1920×1080 | 장면 14종 · 전환 9종 · 효과음 19종 · 톤별 BGM 7종 합성 | p5.js + Web Audio |
| ⑤ 검수 | 숫자 검수, 컨택트시트 | 숫자 검문, 장면 속도(목표 ±30%), 밝기, 움직임, 1초 이상 정지, 자막 속도, 음량 | `src/qa.js` |
| ⑥ 내보내기 | WebM 녹화, 대본 JSON | 화면 + 효과음 + BGM + 내레이션을 한 파일로 | MediaRecorder |

실행: `cd video-engine && npm install && cp .env.example .env`(키 입력) `&& npm start` → http://127.0.0.1:8787

## 3. 전체 흐름 (자동화 완성형)

```
[주제 큐] ─→ [대본 생성] ─→ [기계 검수 1: 대본] ─→ [음성 생성] ─→ [렌더링] ─→ [기계 검수 2: 영상]
 시트/노션     Claude          숫자·길이·금지어        Cartesia       헤드리스      밝기·속도·정지·음량
    ↑                              │ 실패 시 재생성                        │ 실패 시 재렌더(최대 2회)
    │                              ↓                                       ↓
 [실수 노트] ←──── 사람이 거절한 사유 ──── [사람 검수: 컨택트시트 1분] ←── [알림: 카카오톡 나챗방]
                                                     │ 승인
                                                     ↓
                                    [유튜브 비공개 업로드 + 제목·설명·챕터]
```

사람이 꼭 개입하는 지점은 **최종 승인 한 번**이다. 나머지는 실패하면 자동으로 다시 돌고, 두 번 실패하면 사람에게 넘긴다.

## 4. 단계별 로드맵

### 2단계: 헤드리스 렌더 (MP4, 실시간보다 빠르게)
- 지금 WebM 녹화는 영상 길이만큼 실시간으로 걸린다. 엔진의 `renderAt(t)`는 시간만 주면 같은 그림을 그리므로, Playwright로 프레임을 하나씩 찍어 ffmpeg에 넘기면 MP4(H.264)를 실시간보다 빠르게, 프레임 누락 없이 만들 수 있다.
- 오디오는 `OfflineAudioContext`에서 효과음·BGM·내레이션을 같은 이벤트 목록으로 한 번에 렌더해 WAV로 뽑고 ffmpeg에서 합친다.
- 산출물: `render.mjs --script 대본.json --out 영상.mp4`, 세로형(1080×1920 쇼츠) 레이아웃 옵션.

### 3단계: 작업 대기열과 대시보드
- 주제를 여러 개 넣어 두면 순서대로 처리하는 큐(대본 → 음성 → 렌더 → 검수). 상태: 대기 / 대본 / 음성 / 렌더 / 검수 실패 / 승인 대기 / 업로드됨.
- 대시보드: 카드마다 컨택트시트 썸네일, 검수 결과, "승인 / 다시 만들기 / 거절 사유 입력" 버튼. 거절 사유는 실수 노트로 바로 들어간다.
- 저장: 프로젝트별 폴더(대본 JSON, 장면별 WAV, 렌더 MP4, 검수 리포트 JSON). 저장소에 있는 `lib/db`(Drizzle)로 메타데이터를 관리할 수 있다.

### 4단계: 예약 자동화와 업로드
- 매일 정해진 시각에 큐에서 1~2편을 처리하는 예약 실행(서버 cron 또는 Claude 예약 작업).
- 주제 큐 원천: 구글 시트나 노션 데이터베이스의 "주제" 열. 블로그(AI활용연구소) 새 글이 올라오면 그 글을 참고 자료로 넣어 영상화하는 흐름도 같은 큐에 넣을 수 있다.
- 유튜브 Data API로 **비공개** 업로드 → 제목·설명·챕터(장면 beat에서 자동 생성)·태그 채움 → 사람이 공개 전환. API 업로드는 하루 할당량이 있으니(기본 할당량 기준 하루 몇 편 수준) 실제 한도는 Google Cloud 콘솔에서 확인한다.
- 완료 알림: 카카오톡 나챗방으로 "승인 대기 1편 + 컨택트시트 링크".

## 5. 톤 카드 운영 규칙

- 톤 카드는 **규칙 11개 + 대표 장면 + 목표 숫자** 세 가지로 이루어진다. 지금 목표 숫자는 엔진의 기준 렌더를 재서 정했으니, 마음에 드는 완성 영상이 쌓이면 그 영상들을 같은 자(`runQA`)로 재서 다시 맞춘다.
- 지시는 적게: 대본 프롬프트의 고정 규칙은 "목적 하나 + 꼭 지킬 것 몇 개"로 유지하고, 나머지 방향은 톤 카드가 잡는다. 규칙을 늘리고 싶을 때는 검수에서 실제로 반복된 실수만 실수 노트에 올린다.
- 장면 연결: 톤마다 연결 방식이 다르다(종이 무대·파스텔은 끊지 않는 flow, 네온·터미널은 글리치 하드컷, 플랫은 색 와이프, 미니멀 UI는 커서 클릭 후 밀기, 시네마·다큐는 줌). 톤을 고르면 연결 방식이 같이 따라온다.

## 6. 검수 기준 (자동 통과 조건)

| 검사 | 통과 조건 | 실패 시 |
|---|---|---|
| 숫자 검문 | 화면 숫자가 모두 내레이션·주제·참고 자료에 있음 | 대본 재생성 (무조건) |
| 장면 속도 | 평균 장면 길이가 톤 목표의 ±30% | 대사 길이 조정 후 재생성 |
| 밝기·움직임 | 톤 목표 구간 안 | 경고, 사람 판단 |
| 정지 화면 | 1초 넘게 멈춘 구간 없음 | 경고 |
| 자막 속도 | 초당 9자 이하 | 문장 분할 |
| 음량 | 장면 간 내레이션 차이 6dB 이내 | 해당 장면 음성 재생성 |
| 사람 눈 검수 | 컨택트시트 24장: 없는 말을 인용처럼 쓰지 않았는지, 로고가 찌그러지지 않았는지, 휴대폰에서 글씨가 읽히는지 | 거절 사유 → 실수 노트 |

## 7. Cartesia 내 목소리 연결 방법

1. play.cartesia.ai → **My Voices**에서 내 클론 목소리를 선택하고 **Voice ID**를 복사한다.
2. Cartesia 콘솔의 **API Keys**에서 키를 만든다.
3. `video-engine/.env`에 `CARTESIA_API_KEY`, `CARTESIA_VOICE_ID`를 넣거나, 스튜디오 ⚙ 설정과 "목소리 ID" 칸에 넣는다.
4. 모델·API 버전은 기본값 `sonic-3` / `2024-11-13`이다. 계정에서 더 새 모델이나 버전을 쓰고 있으면 설정 화면에서 바꾼다.
5. 단어 타임스탬프를 받는 SSE 경로가 실패하면 서버가 자동으로 `/tts/bytes`(WAV)로 다시 받아, 자막을 글자 수 비례로 맞춘다.

## 8. 비용 감 (대략)

- Claude 대본 1편(표준 2분): 입력 약 3천 토큰 + 출력 약 4~6천 토큰 → `claude-opus-5-5` 기준 1편당 약 0.1~0.15달러.
- Cartesia: 글자 수 기준 과금이며 요금제마다 다르다. 2분 영상 내레이션은 대략 600~900자 분량이니 이용 중인 요금제 표로 계산한다.
- 렌더·검수는 로컬 계산이라 추가 비용이 없다.

## 9. 주의할 점

- **저작권**: 남의 영상·캐릭터·로고·음원은 쓰지 않는다. 마스코트·BGM·효과음은 모두 코드로 만든 오리지널이다. 남의 자료를 언급할 때는 내레이션에 출처를 밝힌다.
- **목소리**: 본인 목소리 클론만 쓴다. 다른 사람 목소리를 쓰려면 본인 동의가 필요하다.
- **AI 표기**: 유튜브는 실제처럼 보이는 합성 콘텐츠에 공개 표시를 요구하는 정책이 있다. 업로드 전에 현재 정책을 확인하고 필요하면 "변경되거나 합성된 콘텐츠" 표시를 켠다.
- **키 관리**: API 키는 `.env`에만 두고 저장소에 올리지 않는다(`.gitignore` 처리됨). 서버는 기본으로 이 컴퓨터(127.0.0.1)에서만 열린다. 외부 공개 배포를 하려면 로그인과 사용량 제한을 먼저 붙인다.
